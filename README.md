## 📖 Overview

A modern, responsive portfolio website showcasing my projects, skills, and experience as a full-stack developer. Built with performance and aesthetics in mind — featuring smooth animations, interactive UI components, and a clean developer-first design.

---

## ✨ Features

- 🎨 **Modern Design** — Clean, minimal UI with smooth Motion.dev animations
- 📱 **Fully Responsive** — Works seamlessly on mobile, tablet, and desktop
- 🌙 **Dark Mode** — Eye-friendly dark theme
- ⚡ **Blazing Fast** — Vite-powered with optimized build output
- 🗂️ **Projects Showcase** — Highlighted projects with live links and tech stacks
- 📬 **Contact Section** — Direct links to GitHub, LinkedIn, and email
- 🧠 **Skills Grid** — Visual display of tech stack and proficiencies

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Framework | React 18, TypeScript |
| Styling | Tailwind CSS |
| Animations | Motion.dev (Framer Motion) |
| Build Tool | Vite |
| Deployment | Vercel |

## 🚀 Getting Started

```bash
git clone https://github.com/kunal202426/portfolio_website.git
cd portfolio_website
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)
